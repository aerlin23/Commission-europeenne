# Commission européenne · 2024–2029

Annuaire indépendant des 27 membres du collège : portraits officiels, pays, fonctions et portefeuilles. Recherche, filtres par pays et sexe, tri alphabétique ou par responsabilités, quiz à 3 ou 4 noms du même sexe, export JSON et CSV.

## Publication

GitHub Pages : Settings → Pages → Deploy from a branch → main → /(root) → Save. Les modifications suivantes sont publiées automatiquement après chaque commit.

## Mise à jour

Les données sont figées au 6 novembre 2026 ; aucune synchronisation automatique n’est activée. Modifier `members.json`, vérifier la fiche officielle et actualiser la date `checkedAt`. Chaque portrait local dans `photos/` provient de l’adresse officielle conservée dans `photo`. Ne pas déduire le sexe d’un nom ou d’une photographie : le champ `gender` utilisé pour le quiz est basé sur les civilités du document de nomination du Conseil européen.

Les fonctions sont codées `PRESIDENT`, `VICE_PRESIDENT` ou `COMMISSIONER`. Le filtre « Présidence et vice-présidences » regroupe la présidente et les six vice-présidents, dont la haute représentante. Tous font partie du collège.

Les groupes politiques parlementaires et les partis nationaux ne sont pas attribués aux commissaires. Le mandat du collège est 2024–2029.
